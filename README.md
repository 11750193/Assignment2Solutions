# 作业 2：软件测试与调试 (Software Testing and Debugging)

## 概述
在这次作业中，你将在开发程序中练习应用软件测试和调试方法。

有 5 个来自不同应用领域的 Python 程序， 目标是：

1. 使用 `doctest` 和 `unittest` **开发全面的测试套件**
2. 对面向对象系统**测试复杂状态和多个属性**。
3. 在有问题的程序中**识别并修复软件错误/问题**。
4. 使用 VS Code 中的测试面板**配置测试**并触发执行。

---

### 问题 1：Doctest（`problem1.py`）

在文档字符串(docstring)中至少添加 **6 个全面的 doctests**。

### 问题 2：带有多个属性的单元测试 Unittest（`problem2.py`, `test_problem2.py`）

在 `test_problem2.py` 中为 `BankAccount` 类实现测试方法。


### 问题 3：带有多个属性的 Unittest（`problem3.py`, `test_problem3.py`）

在 `test_problem3.py` 中为 `Order` 类实现全面的测试用例。


### 问题 4：Unittest（`problem4.py`, `test_problem4.py`）

在 `test_problem4.py` 中为 `MeetingRoom` 类实现测试用例。


### 问题 5：调试（`problem5.py`, `test_problem5.py`）

源代码（`problem5.py`）和完整测试套件（`test_problem5.py`）已经提供。请确认所有测试都能在本地通过。


如果你在上述五个问题中发现任何错误，请进行调试。
